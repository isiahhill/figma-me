Proof of concept

A messy brief in. An approved, brand-safe draft out. A person still says yes.

Generation is the easy part. The process around it is the product: a schema the model has to write inside, brand rules enforced in code, and a gate that fails closed and calls no model.

Where deterministic logic ends and judgment begins

The model reads the brief, drafts inside a schema, rewrites failing spans once, and scores the result. It never decides whether something ships.

The deliberate failure

One command injects 47 percent ROI into a brief that would otherwise pass.

$ npm run break

break    gate=blocked  violations=[CLAIM_NUMBER]  NO payload
injected number blocked; no payload emitted

  rule_id       CLAIM_NUMBER
  severity      block
  message       numeric claim without an approved source: "47 percent"
  span          47 percent

Three things that are on purpose

The gate calls no model

Hard brand rules are code, so a persuasive draft cannot argue its way past them. The model can pull a draft down to review, never up.

Every fact cites a source

A number that is not in the approved claims file becomes a question for a human, never an invention.

There is no send

The handoff builds a create-only payload with no audience attached. Sending, scheduling, and triggering are not implemented rather than merely disabled, and two independent guards fail the test suite if a payload ever grows one.

Run it yourself

Four commands. It needs no keys, no network, and no accounts.

npm ci
npm test        # 86 assertions, 12 of 12 golden scenarios
npm run demo    # clean, messy, and hostile, end to end
npm run break   # the injected statistic, blocked

The brand, the claims table, the briefs, and the payloads on this page are invented for this build. No real company content, customer data, or internal material went into it.

Runs carry no timestamps, so a rerun is byte-identical and a diff in a golden file means a real behavior change.
