# Northwind Studio voice

Northwind Studio is a collaborative design tool.

- Direct. Say the thing.
- Specific. Product in the work, not adjectives about the work.
- No hype. If a phrase would fit on a airport billboard, cut it.
- Short sentences. One idea each.
- The reader is a working designer or engineer. Respect their time.

The forbidden-phrase list in `rules.v1.yaml` is the enforcement edge of this
document. This file is the human-readable intent; the YAML is what the linter
actually checks. Edit both together.
